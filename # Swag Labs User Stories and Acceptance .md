# Swag Labs User Stories and Acceptance Criteria

## Testing the Login page flow for Swag Labs, an online e-commerce store. 

USER STORY:

As a user, I want to login and logout of the website. As a new user, I want to create a new account. 

ACCEPTANCE CRITERIA:

1. A user must enter a username and password to login.

2. A user must have a valid username and password to login.

3. On a failed login, the user did not provide a valid username and/or password.

4. A new user can create a new account.

5. A user can logout at any time.

 

## Testing the checkout payment flow for Swag Labs, an online e-commerce store. 

USER STORY:

As a user, I want to purchase one or more items.

ACCEPTANCE CRITERIA:

1. A user must be signed in to reach the checkout page.

2. The cart must contain at least one item before checkout.

3. A user must enter their first and last name and zip code or postal code before checkout.

4. The zip code is validated for length.

5. On a successful payment an order confirmation is shown.

6. On a successful payment a user can click a button, “Back Home”, to return back to the home screen.

7. On a successful payment a user can click a button, “Generate PDF order”, to receive a PDF receipt of purchase.

8. On a failed payment, an informative error message is shown (for example, "Invalid card number" or "Card expired") and order is not completed.

9. A user can submit payment information.

10. All payment fields are mandatory.

 

## Testing the Products page flow for Swag Labs, an online e-commerce store. 

 

USER STORY:

As a user, I want to select items to purchase, edit the items in my cart, and view the details of the items

 

ACCEPTANCE CRITERIA:

1. A user must be signed in to reach the products page.

2. The user can click an item to view its description and price.

3. A user can filter items alphabetically by item name.

4. A user can filter items by price.

5. A user can click a button, “Add to cart”, to add an item to the purchase cart.

6. A user can add duplicates of the same item to a  purchase cart.

7. A user can click a button, “Remove”, to delete an item from the purchase cart.

8. On a successful item addition, the number on the cart icon increments up by one.

9. On an item removal, the number on the cart icon increments down by one.

10. A user can update the quantity of items on the “Your Cart” page

11. A user can view all the items in a cart and choose to remove items, continue shopping, or  checkout .
